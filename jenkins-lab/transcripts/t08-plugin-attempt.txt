Conclusion recorded for the guide: plugin installation from the update centre is
documented-only in this guide. The mechanism is proven as far as this network lets
it go; on an ordinary connection the same clicks complete in seconds.

--- Addendum, later the same night ---
Jenkins' own update-centre check did eventually land its catalogue on its own
(the update-centre status API later reported data present, with two update
sites configured) - on this slow route it took on the order of ten minutes.
The install itself was then done the manual way: the catalogue JSON was read
directly, the dependency closure of the Pipeline suite and the Git plugin
was computed from it (56 plugins), the .hpi files were fetched with ordinary
downloads, and Jenkins loaded every one of them cleanly after a restart.
See jenkins-lab/resolve_plugins.py for the closure script.
